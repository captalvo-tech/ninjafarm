## Notas verificadas

- O PlayCanvas Engine possui licença MIT e pode operar sem Editor pago; scaffold oficial é Vite + TypeScript.
- A documentação atual de `create-playcanvas` especifica requisitos de Node que devem ser conferidos no momento da instalação.
- Mixamo é gratuito com Adobe ID e permite uso de personagens/animações em videogames comerciais, mas seu auto-rig é para humanoides bípedes.
- Poly Haven declara seus modelos/texturas/HDRI como CC0.
- A licença de Quaternius deve ser verificada **por pack**; não pressupor que todo conteúdo ou arquivo brutos sejam redistribuíveis fora das condições individuais.
- A API gratuita de Open-Meteo é voltada ao **uso não comercial**; serviços comerciais precisam de licença adequada.
- MapLibre é a **biblioteca**, não o provedor gratuito garantido de tiles globais.
